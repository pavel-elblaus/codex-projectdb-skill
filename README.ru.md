# ProjectDB skill for Codex

This description and guide are also available [in English](README.md).

**ProjectDB skill for Codex** помогает разрабатывать и проверять шаблоны и модули ProjectDB с сохранением штатных контрактов платформы. Навык охватывает Twig-шаблоны, JSON-конфигурации, CSS, модульный JavaScript, наследование ресурсов и ручную сборку через `project-map.json`.

Плагин включает навык `projectdb-constructor`, справочные материалы и небольшие примеры контрактов. Инструкции самого навыка написаны на русском языке.

## Что потребуется

Используйте навык в Codex с доступом к исходникам и базовым компонентам вашего проекта ProjectDB. Передайте задачу, инструкции проекта, его настройки и примеры, чтобы Codex учитывал установленные API и версии библиотек.

## Установка

Выберите один способ установки для личного использования или общего рабочего пространства.

### Для личного использования: плагин

В клиенте Codex с поддержкой каталогов плагинов добавьте источник:

```text
codex plugin marketplace add pavel-elblaus/codex-projectdb-skill --ref main
```

Откройте каталог плагинов приложения, выберите источник **ProjectDB for Codex** и установите **ProjectDB for Codex**. Если источник не появился, перезапустите приложение.

### Для личного использования: самостоятельный навык

Для прямой установки навыка попросите Codex:

> Используй $skill-installer и установи навык из https://github.com/pavel-elblaus/codex-projectdb-skill/tree/main/plugins/projectdb/skills/projectdb-constructor.

Этот способ устанавливает локальную копию навыка. Выберите плагин или самостоятельный навык, чтобы избежать двух вариантов с одинаковым именем.

### Для команды: плагин рабочего пространства

Администратор рабочего пространства может импортировать репозиторий и предоставить плагин участникам. Для нескольких рабочих пространств импорт выполняется в каждом отдельно.

1. Откройте [Admin Console](https://admin.openai.com), выберите рабочее пространство и перейдите в **Plugins → Add → Import marketplace**.
2. В **Source** укажите `https://github.com/pavel-elblaus/codex-projectdb-skill`.
3. Поле **Path** оставьте пустым.
4. В **Branch, tag, or commit** укажите **`main`**, чтобы получать дальнейшие обновления.
5. Нажмите **Import marketplace** и выполните вход в GitHub, если появится запрос.
6. Найдите **ProjectDB for Codex** и настройте установку: **Available** для самостоятельной установки участниками или **Installed** для подходящих ролей, если эта настройка доступна.
7. Проверьте, что автоматическая синхронизация каталога включена. Участники устанавливают плагин, если администратор не назначил автоматическую установку.

Доступность зависит от настроек и разрешений рабочего пространства. Подробности — в [официальной инструкции импорта и синхронизации](https://help.openai.com/en/articles/20001504-importing-and-syncing-plugin-marketplaces-from-github).

## Использование

Выберите **ProjectDB for Codex** в доступном списке плагинов и опишите задачу. Например:

> Используй навык projectdb-constructor. Прочитай AGENTS.md проекта и доработай модуль ProjectDB с сохранением входящих данных и штатных контрактов.

В локальных клиентах с выбором навыков можно явно вызвать `$projectdb-constructor`.

## Обновления

Для плагина, установленного лично, обновите источник каталога:

```text
codex plugin marketplace upgrade pavel-projectdb-skills
```

Для самостоятельной установки попросите Codex обновить установленный навык из того же источника GitHub.

Каталоги рабочего пространства по умолчанию проверяют обновления ежедневно. Чтобы обновить раньше, администратор может открыть **Plugins → Marketplaces → ProjectDB for Codex → Sync now**. Для получения новых версий оставьте источником импорта ветку `main`.
