# Работа с плагином

Этот репозиторий распространяет существующий навык ProjectDB. Техническое имя плагина — `projectdb`, навыка — `projectdb-constructor`, каталога — `pavel-projectdb-skills`. Сохранять эти имена при обновлениях.

Единственный источник навыка находится в `plugins/projectdb/skills/projectdb-constructor/`. Локально подключать эту папку через ссылку; редактировать исходники прямо в репозитории. Копии для последующего переноса не поддерживать. Новые файлы явно добавлять в список `skillFiles` в `scripts/skill-package.mjs`.

В навык включать только общие правила ProjectDB и нейтральные примеры. Названия отдельных проектов, их домены, локальные пути, контент, настройки и частные решения оставлять в документации соответствующих проектов. Персональные разрешения пользователя не распространяются на установленные копии других пользователей.

Если владелец явно включил режим автора через `git config --local projectdb.autoPublish true`, после завершённой доработки навыка запускать `node scripts/publish.mjs --auto`. Скрипт проверяет пакет, повышает версию при изменении плагина, делает commit и push. Если прямое Git-подключение недоступно, использовать подключение GitHub для эквивалентной проверенной публикации; о невозможности публикации сообщать явно. Не обходить проверки и не делать force push. Версия плагина не связана с версиями пакетов сайтов ProjectDB.

Для обычных пользователей публикация требует указания владельца. Не редактировать установленные кеши плагинов. Потребители рабочего пространства получают опубликованные изменения через штатную синхронизацию marketplace с веткой `main`.
