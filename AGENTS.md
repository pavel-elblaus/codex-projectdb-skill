# Работа с плагином

Этот репозиторий распространяет существующий навык ProjectDB. Техническое имя плагина — `projectdb`, навыка — `projectdb-constructor`, каталога — `pavel-projectdb-skills`. Сохранять эти имена при обновлениях.

Публичная копия находится в `plugins/projectdb/skills/projectdb-constructor/`. Для переноса знаний из локального навыка автора использовать `node scripts/sync-skill.mjs --version X.Y.Z`; скрипт нормализует публичную копию и не изменяет локальный источник. При переносе новые файлы явно добавлять в список `skillFiles` в `scripts/skill-package.mjs`. Правки публичной копии напрямую согласовать с локальным источником до следующей синхронизации.

Персональное разрешение автора на автоматическую актуализацию локального навыка не распространяется на установленные копии других пользователей. В публичный пакет включать общие правила и нейтральные примеры; данные сайтов и локальные пути оставлять в соответствующих проектах.

Перед публикацией выполнить `node scripts/validate.mjs`, проверить `git diff` и повысить `version` в `plugins/projectdb/plugin.json`, если изменилось содержимое плагина. Версия плагина не связана с версиями пакетов сайтов ProjectDB.

Публикация изменений в GitHub требует указания владельца. Не редактировать установленные кеши плагинов и не создавать расписание для загрузки изменений. Корпоративные потребители получают опубликованные изменения через штатную синхронизацию marketplace с веткой `main`.
