# Работа с плагином

Этот репозиторий распространяет навык ProjectDB. Техническое имя плагина — `projectdb`, навыка — `projectdb-constructor`, каталога — `pavel-projectdb-skills`. Сохранять эти имена при обновлениях.

## Документация

Публичное описание хранить на двух языках: `README.md` — английский, `README.ru.md` — русский. В начале каждого файла оставлять ссылку на другой язык. При изменениях обновлять обе версии согласованно.

README предназначены для пользователей: назначение, необходимые исходники, установка, использование и получение обновлений. Настройку режима автора, публикацию, проверки и структуру репозитория описывать здесь.

## Исходники и содержание навыка

Единственный источник навыка находится в `plugins/projectdb/skills/projectdb-constructor/`. Локально подключать эту папку через ссылку; редактировать исходники прямо в репозитории. Копии для последующего переноса не поддерживать. Новые файлы явно добавлять в список `skillFiles` в `scripts/skill-package.mjs`.

В навык включать только общие правила и подтверждённые контракты ProjectDB, а также нейтральные примеры. Названия отдельных проектов, их домены, локальные пути, контент, настройки, персональные предпочтения и частные решения оставлять в документации соответствующих проектов. Перед переносом знания убрать привязку к исходному случаю; неподтверждённое обобщение оставить в проекте. Персональные разрешения пользователя не распространяются на установленные копии других пользователей.

## Подключение режима автора

Нужны Git, Node.js 18.19 или новее, настроенные Git-имя и email, а также доступ к отправке в свой репозиторий. Рабочая папка должна разрешать запись Git и Node.js. При создании собственного форка сначала указать его адрес в манифесте и origin.

В Windows после клонирования репозитория выполнить из его корня:

```powershell
.\scripts\setup-author.ps1
```

Скрипт подключает ветку `main`, проверяет пакет, сохраняет прежний установленный навык в резервную папку и создаёт junction на исходники. Затем он включает режим автора только для этого локального репозитория: `git config --local projectdb.autoPublish true`.

Режим автора включается владельцем локально и не передаётся при установке плагина. Отключение: `git config --local projectdb.autoPublish false`.

## Публикация

Если владелец явно включил режим автора, после завершённой доработки навыка или его документации запускать:

```text
node scripts/publish.mjs --auto
```

Скрипт проверяет пакет, повышает patch-версию при изменении плагина, создаёт commit и отправляет его в `main`. Изменения только в документации репозитория не требуют повышения версии плагина. Версия плагина не связана с версиями пакетов сайтов ProjectDB.

Незавершённые правки после каждого сохранения не публиковать. При ошибке проверки, конфликте или проблеме доступа сохранить локальные изменения и явно сообщить о невозможности публикации. Не обходить проверки и не делать force push. Если прямое Git-подключение недоступно, использовать подключение GitHub для эквивалентной проверенной публикации.

Предварительная проверка без commit и push:

```text
node scripts/publish.mjs --check
```

Для обычных пользователей публикация требует указания владельца. Не редактировать установленные кеши плагинов. Потребители рабочего пространства получают опубликованные изменения через штатную синхронизацию marketplace с веткой `main`.

## Проверки

```text
node scripts/validate.mjs
```

Проверяются каталог marketplace, основные поля манифеста, состав файлов навыка, frontmatter, локальные ссылки, формат JSON, синтаксис JavaScript, адреса сайтов и типичные следы персональных данных.

GitHub Actions выполняет эту проверку на Linux и Windows, а также проверяет процесс публикации на временном локальном Git-репозитории. На Windows дополнительно проверяется подключение режима автора с резервной копией и junction. Эти проверки не заменяют пробную установку в целевом рабочем пространстве и проверку поведения на реальном ProjectDB.

## Структура

```text
.agents/plugins/marketplace.json       Каталог для импорта из GitHub
plugins/projectdb/plugin.json          Манифест и версия плагина
plugins/projectdb/skills/
  projectdb-constructor/
    SKILL.md                          Основные инструкции
    agents/openai.yaml                Отображение навыка
    references/                       Правила и справочники
    examples/                         Примеры контрактов
scripts/                              Проверка, подключение и публикация
```

[Формат плагинов OpenAI](https://developers.openai.com/plugins/build/plugins).
